Getting LetterLinks by Person

Note that each step involves editing each scenario to adjust the output (manual save)


---- FOR EACH PART ---

for Addressees (lettersTo.xml):
(now all xslts in TOlists)

1.  runList (w/intro and list commented out) + getAddresees = addresees.xml (save in working) -- TOget
2.	addresees.xml + sortByCorresp.xml = alphaAdd.xml (save in working) -- TOsort
3.	alphaAdd.xml + mergeCorresp.xsl = lettersTo.xml -- TOmerge
4.	lettersTo.xml + checkCorrspList.xsl = checkCorrespList.xml -- for later, for Lynda -- TOcheck


for people mentioned (lettersIn.xml):
(now all xslts in INlists)

1.	runList (w/intro and list commented out) + getMentions.xsl = mentioned.xml (save in working) -- INget
2.	mentioned.xml + mergeMentions.xsl = mentMerged.xml (save in working) -- INsort (it is sorting and merging)
3. 	mentMerged.xml + fixDupMentions.xsl = lettersIn.xml -- INmerge (merging duplicates and generating the number of mentions)


Next:

First, move combineLists xml docs from generateLists folder to main XML folder.

1. open combineListsTO and run combineListsTO scenario which uses combineListsTO.xsl and saves as TOall.xml
2. open combineListsIN and run combineListsIN scenario which uses combineListsIN.xsl and saves as INall.xml
3. open INall.xml and run makeList scenario which uses toWebMentioned.xsl and saves as paratext/mentioned.html
4. open INall.xml and run makeCSV scenario which uses INlists/makeMenCSV.xsl to make the csv files for people mentioned
5. run corresp.xml using toWebCorresp.xsl to make the corresp.html page and the csv files for correspondents (if there is a person who is mentioned who is also someone Southey writes to, the mentioned csv files will be overwritten, but don't worry because they contain letters mentioned in as well as to.)
